# EdgeData

**Do sensor ao DOI.** Plataforma para planejar experimentos, coletar dados em campo e laboratório
(manualmente ou a partir de sistemas embarcados) e transformar essas observações em datasets
científicos rastreáveis, versionados e reprodutíveis.

> Status: em desenvolvimento — fase **MVP**.

## Estrutura do repositório

```
EdgeData/
├── apps/mobile/     # Aplicativo (Expo / React Native, offline-first)
├── firmware/        # Bibliotecas e exemplos para ESP32 e outros embarcados
├── schemas/         # JSON Schemas públicos (manifesto de dispositivo, etc.)
├── docs/            # Análise, requisitos, arquitetura, roadmap e guias
└── scripts/         # Scripts de build e utilidades
```
