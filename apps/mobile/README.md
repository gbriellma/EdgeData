# EdgeData — App mobile

Aplicativo offline-first (Expo SDK 54 / React Native 0.81 / TypeScript) para planejar experimentos
e coletar dados em campo e laboratório.

## Desenvolvimento

```bash
npm install
npx expo start
```

Funcionalidades que usam módulos nativos (Bluetooth, ZIP nativo) exigem um *development build*:

```bash
npx expo run:android
```
